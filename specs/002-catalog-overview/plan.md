# Implementation Plan: Catalog Overview

**Branch**: `002-catalog-overview` | **Date**: 2026-10-09 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-catalog-overview/spec.md`

## Summary

Turn the home page into a developer-portal entity overview: the identity card gains the profile
photo, and three new cards follow — Key numbers (three facts with organisation and period,
locale-formatted), About (three sentences) and Links (LinkedIn, GitHub). The build renders a
1200 × 630 sharing image per language from the same photo and dictionary, and every page
declares it. Still zero client-side JavaScript.

## Technical Context

**Language/Version**: TypeScript 6.0 (strict); Node.js 24 LTS in CI

**Primary Dependencies**: Astro 7.3 `astro:assets` `<Picture>` (sharp, already installed);
build-time only: satori 0.47.1, @resvg/resvg-js 2.6.2, @fontsource/inter 5.3.0 (WOFF for Satori)

**Storage**: `src/assets/profile.jpg` (cropped source photo); content in TypeScript modules

**Testing**: Vitest (key numbers, formatting, meta image, image metadata), Playwright + axe
(overview cards, photo, layout shift, image weight, sharing tags, both languages)

**Target Platform**: GitHub Pages, evergreen browsers

**Project Type**: static website

**Performance Goals**: constitution budgets on every page; photo ≤ 60 KB at 2×; CLS 0

**Constraints**: no client JS; no third-party requests; no image metadata; bilingual parity

**Scale/Scope**: 2 pages changed, 2 generated images, ~15 new strings per locale
